# 無障礙生活實驗室｜3D 原型 V0.1

兩房一廳可旋轉 3D 住宅初版。使用 Three.js ES modules CDN，不含商業模型或商品資料。

## 使用

在資料夾執行 `python -m http.server 8000`，瀏覽 `http://localhost:8000`。或將 `index.html` 放至 GitHub Pages。

需要網路連線以載入 Three.js。點擊房間切換視角，點擊橘色的輪椅、洗澡椅、照顧床或助行器查看資訊卡。

## 範圍與限制

此版為幾何模型與操作驗證，尚未達到設計師級高擬真材質。沒有真實商品、補助金額、購物車、金流。模型不代表法規核准的無障礙尺寸。後續應替換成高品質 GLB 模型並核對官方補助資料。
